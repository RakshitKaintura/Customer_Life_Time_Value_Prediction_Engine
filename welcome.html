Quick Start

Clone & Setup

Clone repository and create Python 3.11 virtual environment

uv venv --python 3.11 .venv\Scripts\Activate.ps1 uv pip install -e "[ml]"

Configure Environment

Set up required environment variables in .env file

SUPABASE_URL=your_url SUPABASE_SERVICE_ROLE_KEY=your_key DATABASE_URL=postgres://...

Run API Server

Start the FastAPI development server with auto-reload

uvicorn backend.api.main:app --reload

Access & Explore

Open interactive API docs and explore available endpoints

http://localhost:8000/docs
